# Green Core

Green Core — iOS-застосунок для моніторингу та керування розумною фермою на базі ESP32. Застосунок отримує телеметрію й надсилає команди через Bluetooth Low Energy (BLE). Інтерфейс українською мовою.

## Можливості

- Показ температури, вологості повітря та освітленості.
- Моніторинг вологості ґрунту на двох ярусах і стану чотирьох реле.
- Відображення рівня води та попередження про низький рівень.
- Керування реле, RGB-лампою першого ярусу й RGB-стрічкою другого ярусу.
- Пошук BLE-пристроїв, підключення й перегляд стану з’єднання.
- Світла й темна теми.

## Технології

- Swift 5, SwiftUI та Combine.
- CoreBluetooth для BLE-з’єднання з ESP32.
- UserNotifications для локальних сповіщень.
- Xcode-проєкт: `SmartFarm.xcodeproj`, схема й target: `SmartFarm`.
- Мінімальна версія iOS у налаштуваннях target: iOS 17.6.

## BLE-інтеграція з ESP32

Застосунок шукає доступні BLE-пристрої, а після підключення шукає сервіс і характеристики з такими UUID:

| Призначення | UUID | Властивості, потрібні застосунку |
| --- | --- | --- |
| Сервіс SmartFarm | `12345678-1234-1234-1234-123456789ABC` | — |
| Дані сенсорів | `12345678-1234-1234-1234-123456789ABD` | Notify та/або Read |
| Керування | `12345678-1234-1234-1234-123456789ABE` | Write |

Дані сенсорів мають надходити як UTF-8 JSON. Парсер підтримує як повну модель, так і скорочені ключі. Наприклад:

```json
{
  "temp": 22.5,
  "hum": 55.0,
  "light": 68,
  "water": 74,
  "soil": [41, 45, 52, 49],
  "relays": [true, false, false, true],
  "rgbLights": { "r": 255, "g": 160, "b": 40, "enabled": true },
  "stripLights": { "r": 40, "g": 100, "b": 255, "enabled": true }
}
```

Також приймаються назви `temperature`, `humidity`, `lightLevel`, `waterLevel`, масиви `soilMoisture1` і `soilMoisture2`, або окремі поля `soil1`–`soil4`. `relays` може містити булеві значення або `0`/`1`. Модель очікує відсоткові значення для вологості ґрунту, освітленості й рівня води.

Команди записуються у характеристику керування у форматі JSON:

```json
{ "type": "relay", "index": 0, "state": true, "timestamp": 0 }
{ "type": "rgb", "enabled": true, "r": 255, "g": 160, "b": 40, "timestamp": 0 }
{ "type": "strip", "enabled": true, "r": 40, "g": 100, "b": 255, "timestamp": 0 }
{ "type": "request", "timestamp": 0 }
```

`timestamp` під час роботи генерується застосунком як Unix-час у секундах; у прикладах він дорівнює `0`. ESP32 має обробляти `relay`, `rgb`, `strip` та `request` відповідно. Запит даних читає характеристику сенсорів, якщо вона підтримує Read; інакше команда `request` надсилається характеристикою керування.

> UUID та формат повідомлень мають збігатися з прошивкою ESP32. Їх можна змінити у `SmartFarm/ViewModels/BluetoothManager.swift`; правила розбору вхідного JSON описані в `SmartFarm/Services/DataParser.swift`.

## Дозволи та сповіщення

У `SmartFarm/Info.plist` задано опис використання Bluetooth і фонові режими `bluetooth-central`, `fetch` та `remote-notification`. Для отримання даних у фоні iOS може обмежувати час і частоту виконання; поведінка залежить від системи та конфігурації пристрою. Сповіщення про втрату з’єднання й низький рівень води залежать від дозволу користувача на сповіщення.

## Відомі межі реалізації

- Сумісність із конкретною прошивкою ESP32 визначається UUID сервісу/характеристик і JSON-контрактом вище.
- Сканування виконується без фільтра за сервісом, після чого застосунок перевіряє потрібний сервіс при підключенні.
- Керування доступне лише за активного BLE-з’єднання та наявної характеристики запису.
- Реальну поведінку BLE, датчиків і фонової роботи потрібно перевіряти на фізичному пристрої з відповідною прошивкою ESP32.
